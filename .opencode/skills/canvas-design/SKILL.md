# Canvas Design

## Design Philosophy Creation

1. **Name the movement** (1-2 words): e.g. "Brutalist Joy" / "Chromatic Silence" / "Metabolist Dreams"
2. **Articulate the philosophy** (4-6 paragraphs):
   - Space and form
   - Color and material  
   - Scale and rhythm
   - Composition and balance
   - Visual hierarchy
3. Emphasize craftsmanship - the work should appear meticulously crafted

## Canvas Creation

- Use the design philosophy as foundation
- Create single page, highly visual, design-forward output
- Use repeating patterns and perfect shapes
- Minimal, clinical typography
- Limited, intentional color palette
- Text as visual element, not explanation

## Principles
- VISUAL PHILOSOPHY: Create an aesthetic worldview
- MINIMAL TEXT: Text is sparse, essential-only
- SPATIAL EXPRESSION: Ideas communicate through space, form, color, composition
- PURE DESIGN: Art objects, not documents with decoration
- EXPERT CRAFTSMANSHIP: Looks like it took countless hours
